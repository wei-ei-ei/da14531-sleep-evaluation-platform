# 项目概述

## 项目定位

DA14531 睡眠生理采集与算法验证平台面向 Renesas DA14531 SmartBond TINY Module Development Kit，使用现成光学、运动和温度传感器，演示从生理信号采集到睡眠相关特征分析的完整 BLE 数据链路。

项目重点是可复现的信号采集、BLE 传输、低功耗验证和算法分析。开发板负责作为稳定、可测量的硬件基线，便于比较传感器、采样策略和软件处理结果。

## 目标用户

- 使用 DA14531 和 SDK6 的嵌入式开发者。
- 研究或学习睡眠信号、PPG 和心率变异性的人员。
- 评估 PPG、加速度计和温度模块的工程人员。
- 关注 BLE 健康感知端到端实现的读者。

## 计划能力

- 通过 I2C 采集 PPG、三轴体动和体表温度趋势。
- 在设备端提取心率、RR 间期、HRV、活动量和信号质量。
- 同时提供原始数据和低速率特征数据 BLE 服务。
- 在手机或电脑上显示实时曲线并导出 CSV。
- 对记录数据进行回放、睡眠/清醒分析和研究性浅睡/深睡分析。
- 使用 SmartSnippets Toolbox Power Profiler 验证不同工作状态的电流。

## 设计原则

- 原始信号和派生特征使用统一时间戳，确保结果可追溯。
- 原始诊断数据和正常运行时的特征数据分开传输。
- 记录信号质量，而不是隐藏缺失或受运动干扰的数据片段。
- 任何分析结果都应能够从保存的数据重新计算。
- 明确说明消费级和研究级睡眠监测的能力边界。

## 非目标

- 不用于疾病诊断或治疗。
- 不宣称已经完成医疗器械认证。
- 不宣称临床级睡眠分期、心率或血氧准确率。
- 不把开发板验证结果描述为已经量产的消费产品。
